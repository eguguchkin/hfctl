# Brief: engine/0.4.7 — образ hipfire 0.4.6 → 0.4.7

## Goal (формулируемый, проверяемый)

Дефолтный пин образа в hfctl = `ghcr.io/warpfront/hipfire:0.4.7`: новые
инсталляции и `hfctl use` тянут 0.4.7; доки продукта отражают новый пин;
изображение 0.4.7 подтверждено живым прогоном (EXP-104).

## DoD (единственный носитель)

1. Пин `hfctl:35–36` (`@type`-комментарий + `IMAGE=`) `0.4.6` → `0.4.7`;
   пина 0.4.6 в продукте больше нигде нет (grep: `hfctl`, `lib/`, `install.sh`,
   `README.md`, `tpl/`).
2. Док-строки, говорящие о ПИНУ образа: заголовок модуля и golden-пометка
   `lib/stack_files.sh` → 0.4.7 + mandated-пометка байт-идентичности
   compose-голден'ов для 0.4.5/0.4.6/0.4.7 (F-0.4.7.3). `tpl/compose/`
   НЕ меняется (golden'ы валидны).
3. FACTS.md: секция «Движок 0.4.7» (F-0.4.7.1…6) — внесена оркестратором
   до кода; developer не дублирует.
4. Внутренние проверки зелёные: `bash -n hfctl lib/*.sh`,
   `python3 -m py_compile tpl/python/*.py`, `hfctl` без аргументов → usage
   rc=1, `hfctl status --json` с подменой PORT на чанковый (корректный
   отказ, не крах).
5. EXP-104 (машинная приёмка, GO пользователя): recreate стека с дефолтным
   пином (0.4.7) → healthy → smoke (dflash:true) → bench quick; регрессия
   против бейзлайнов 0.4.6: машина B quick ≈75.8 tok/s (соло-код), che-evo
   solo ≈131.0 tok/s / τ13.18 (эталон 0.4.6; отклонение <5% и dflash:true —
   нет регрессии).
6. Ревью APPROVED; сабстэдж закрыт статусным коммитом (STATE.md + history.md).
