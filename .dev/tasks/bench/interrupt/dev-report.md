## Known limitations / assumptions

- **pkill**: фикс использует `pkill -P` (procps). В Ubuntu/Debian (целевая
  платформа hfctl) procps — Essential, отдельного гейта не требует; в
  ocbox-песочнице тоже есть (проверено живым прогоном).
- **SIGINT «ignored» на входе** (запуск `hfctl bench &` из неинтерактивного
  скрипта / nohup-подобные каналы): bash не может затрапить сигнал,
  игнорируемый на старте (POSIX) — прерывание в этом режиме невозможно из
  внутри bash без exec-обёртки со сбросом маски (переусложнение, не делали;
  в терминале и при обычном `kill -INT` группы — контракт выполняется).
  Это объясняет расхождение «живая машина rc=0 / песочница rc=130» из EXP-102.
- Пока bash ждёт foreground-ребёнка, трап откладывается до его смерти — при
  Ctrl-C/kill группы curl получает сигнал тоже и умирает сразу; одиночный
  `kill -INT <pid-bash>` без группы дождётся текущего запроса (в docs
  не обещано, на контракт не влияет).
- date-шим и fake-сервер — только песочница, в продукт не входят (как в
  bench/concurrency).
