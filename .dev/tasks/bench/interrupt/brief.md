# Brief: bench/interrupt — прерываемость `hfctl bench` по Ctrl-C

Находка EXP-102 (hflab `.local-analysis/bench-concurrency-exp/EXP-101.txt`,
2026-11-14): на живой машине SIGINT процессной группе НЕ прерывал прогон —
он дожил до rc=0 со штатным артефактом; в офлайн-песочнице developer'а тот
же сигнал давал rc=130. Поведение среда-зависимое, явного контракта нет.

## Факты (проверены)

- `lib/bench.sh` `cmd_bench`: trap только `EXIT` (строка ~590, rm -rf
  BENCH_TMP). INT-трапа нет.
- `bench_parallel`: N curl'ов запускаются ФОНОВЫМИ subshell'ами `( … ) &` +
  `wait`. POSIX-семантика нефлагаемого bash: фоновые джобы наследуют SIGINT
  «ignored» — терминальный Ctrl-C их НЕ убивает, а main-скрипт без трапа
  умирает/не умирает в зависимости от среды (в песочнице — 130, на живой —
  нет; на `wait` без трапа bash прерывается, с фоновыми curl'ы доживают).
- Последствия «убитого» main-скрипта при живых фоновых curl: EXIT-trap
  сносит BENCH_TMP, пока curl'ы в него пишут — безвредно по факту (файлы
  больше никто не читает), но осиротевшие запросы продолжают грузить очередь
  сервера без владельца.
- Частичный артефакт не грозит: JSON пишется один раз в конце.

## Goal

Ctrl-C (SIGINT) детерминированно прерывает `hfctl bench`: разумное rc
(130/143), без артефакта, без temp-мусора, без осиротевших запросов к
серверу. Поведение одинаково в TUI-терминале и при `kill -INT` группы.

## DoD

1. Офлайн-репро (песочница developer'а, fake-сервер + `script`/pty или
   `timeout -s INT` на группу): ДО фикса — один из двух кейсов не прерывается
   (зафиксировать какой); ПОСЛЕ — оба прерываются.
2. Минимальный фикс в `lib/bench.sh`: явный INT (и TERM) trap в cmd_bench:
   сообщение «прервано», убить дочерние curl/process-group-потомков, rc 130
   (TERM → 143). Артефакт при прерывании НЕ пишется; temp чистится
   существующим EXIT-trap'ом. Один файл продукта.
3. Строка в usage `hfctl bench` / README: семантика Ctrl-C (прерывает,
   частичный прогон не сохраняется).
4. Существующие проверки не сломаны: bash -n, разбор флага, --compare на
   фикстурах, offline-E2E штатного прогона (артефакт пишется как раньше).
5.SPEC-шв: соответствует .dev/tasks/bench/concurrency/SPEC.md:81 («rc
   130/143 допустимы; сервер не…») — перечитать хвост строки и не
   противоречить.
6. Живая проверка — ЗА ОРКЕСТРАТОРОМ после пуша+доставки (машина evo,
   короткий quick --parallel 4 + `timeout -s INT` группы; критерии: rc,
   ноль новых артефактов, очередь /stats dren до 0, temp чист). Машины в
   этом сабстэдже не трогать.

## Constraints

- Один файл продукта (lib/bench.sh) + usage/README строки. Новый Python —
  нельзя. tpl/bench не трогать (md5 253c7ac5).
- Не переписывать bench_parallel на foreground — трап + kill потомков
  достаточны (ponytail).
- Штатный (непрерываемый) путь не должен измениться ни на байт вывода.
