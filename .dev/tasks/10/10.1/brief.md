# Brief: watch-tui — дашборд для `hfctl watch`

## Goal (statable, checkable)
`hfctl watch` становится TUI-дашбордом (блоки: движок / железо / скорость с
sparkline / память / логи) на TTY; в не-TTY — стриминг строк, где строка
БЕСУСЛОВНО раз в N секунд и содержит полный срез (prefill tok/s, decode tok/s,
очередь, ошибки, ретраи, кэш, MemAvailable/Total+swap, GPU temp/sclk/power/busy,
Tctl CPU). Все данные — из /stats, /metrics, host sysfs, `podman logs -f`;
движок не меняется.

## DoD (checklist; единственный носитель DoD)
1. `hfctl watch` в TTY открывает TUI: блоки «движок» (модель/uptime/очередь/
   ошибки/τ), «железо» (sclk/busy/power/GPU temp/Tctl), «скорость»
   (prefill + decode tok/s, live и avg, sparkline ~60 с), «память»
   (MemAvailable/Total + bar, swap, KV pages), «логи» (live `podman logs -f`,
   нижняя зона на всю ширину).
2. Клавиши: `q` — выход, `+`/`-` — интервал (1..10 с), пауза логов; статус-бар.
3. Минимальный терминал 80×24; при меньшем — деградация (блоки сжимаются),
   не краш; при TERM не-UTF8/узком — корректная деградация без трейса.
4. Сервер /stats недоступен: блок «движок» = «недоступен», блоки RAM/датчиков/
   логи продолжают работать (TUI не крашится, цикл продолжается).
5. Пороги цветом: MemAvailable < 10 GiB — красный; Tctl > 80° — красный;
   busy≈0 при queue>0 — подсветка.
6. Не-TTY: строчка БЕСУСЛОВНО раз в N секунд (default 2) с полным срезом
   (состав — по SPEC.md/D2); `--interval N` работает в обоих режимах;
   «сервер недоступен» — строка раз в 30 с (как сейчас), без дублей.
7. Общий коллектор данных для обоих режимов (один код, два рендерера);
   bash `cmd_watch` — только разбор аргументов + exec python3; мёртвый код
   (bash-петля, `watch_stats.py` и `gpu_temp`, если становятся ненужными)
   удалён, а не закомментирован.
8. Python: только stdlib (curses/urllib/subprocess/threading); файл в
   `tpl/python/`; один процесс; лог-стример в отдельном потоке не дёргает
   перерисовку и HTTP.
9. Регрессия: `bash -n` на все sh, `py_compile` на все python; `hfctl status`,
   `logs`, `doctor` не тронуты и работают (регрессия по spec/hfctl.md §watch —
   строка-описание в spec/hfctl.md и README обновлены на новое поведение).
10. Внешняя приёмка (BLOCKED-EXTERNAL, через EXP-скрипты + GO пользователя):
    TUI живой на реальной машине по SSH (рендер блоков, логи текут, цифра
    prefill появляется при генерации); стрим-режим `hfctl watch | tee f` даёт
    строки раз в N с; стрим-режим в лог-файле не портит TTY (альтернативный
    экран не просачивается).
11. `spec/hfctl.md` (строка `hfctl watch`) и `README.md` (команда watch)
    описывают новое поведение; `spec/state.md` — статусным коммитом
    оркестратора после закрытия.

## Constraints and known traps
- Движок не меняется: метрики/пути — из `flow/FACTS.md` (имена сверены по
  0.4.5 `metrics.rs`; live prefill = Δprompt_tokens_total/Δt).
- `gpu_temp()`-логика (max по AMD hwmon) и чтение /sys — на хосте;
  `podman logs -f` — контейнер `hipfire_hipfire_1` (глобала CONTAINER).
- Не нарушать «тихую философию» только там, где она была осознанной:
  ДА — самовосстановление при недоступности; НЕТ — «печатать только при
  изменении» (D2 отменяет именно это для стрим-режима).
- TUI обязан корректно выйти по `q` (альтернативный экран снять) и на
  SIGINT/SIGTERM (иначе `hfctl watch` в скрипте-пайпе оставляет терминал
  кривым — но в пайпе TUI не запускается, см. D1).
- Python-версия на целевых Ubuntu 26.04: только синтаксис, совместимый с
  3.8+ (не использовать 3.12-only конструкции).
- Не коммитить; не трогать `tpl/bench/`, `spec/state.md` (AGENTS.md dev-flow).
- Sparkline-история держится в RAM (deque), без файлов; при интервале ≠2 с
  ширина истории пересчитывается, не ломается.
