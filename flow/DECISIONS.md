# DECISIONS

## 2026-11-12 (установлено пользователем)
- **D1.** `hfctl watch` в TTY открывает TUI-дашборд; в не-TTY (пайп/лог) —
  стриминг строк. Одна команда, поведение `top`/`htop`.
- **D2.** Стрим-режим: строка БЕСУСЛОВНО раз в N секунд (отказ от «только при
  изменении счётчиков» — текущая реализация не отслеживает температуру и
  упускает всплески); строка — полный срез: очередь/обслужено/ошибки/ретраи,
  prefill tok/s, decode tok/s, кэш, MemAvailable/Total + swap,
  GPU temp/sclk/power/busy, Tctl CPU.
- **D3.** Клавиши TUI — минимум: `q`, `+`/`-` (интервал), пауза логов.
- **D4.** Не менять движок hipfire: все данные уже есть в /stats, /metrics и
  sysfs (FACTS.md).
- **D5.** Реализация (оркестратор, рекомендовано и принято): один
  python3+curses-файл в `tpl/python/` со stdlib; общий коллектор данных для
  TUI и стрим-режима (`--plain`); `cmd_watch` сокращается до разбора аргументов
  + `exec python3`; интервал — период и перерисовки TUI, и строчки стрима.
  (Уточнение: отдельного `--plain`-флага нет — режим выбирается по
  `isatty()` внутри python, что делает D1 и DoD 6; `--plain` не введён.)
- **D6.** (пользователь) Приёмка EXP-001..003 — на машине B (128 GiB,
  gfx1151, flash-multi), не на прод (машина A).
- **D7.** (пользователь) Доставка нового бинаря — официальный путь:
  commit → `git clone` + `install.sh` на целевой машине (пуш пользователь
  выполнил с хоста; коммиты `812b6a0`, `97e971f`).
- **D8.** (пользователь, 2026-11-13) Семантика скоростей — ЧЕСТНЫЕ метрики
  без правок движка: decode tok/s = `recent_tok_s` (последний завершённый
  запрос), prefill tok/s = среднее гистограммы `hipfire_prefill_tokens_per_second`,
  «обработка» = очередь + GPU busy + sparkline по дельтам счётчиков (пики на
  завершении). «Live»-обещание снято: движок обновляет счётчики токенов
  только в done-событии (FACTS.md), live-скорость в процессе НЕ существует.
- **D9.** (пользователь) Лог-зона TUI сидируется `podman logs --tail 50`
  при старте (стартовые строки сразу видны; live-поток по-прежнему идёт).
- **D10.** (оркестратор, 2026-11-13) Scope правки 7: в сабстэдже чистится
  продукт (tpl/python) + blackboard текущего сабстэджа (flow/watch/watch-tui
  + flow/external) + top-level blackboard; pre-existing `spec/task-7/8/9.md`,
  `spec/state.md`, `spec/plan.md` (имена машин — унаследовано от этапом 8–9,
  принято до этого решения) — НЕ трогать (закрытые контракты, append-only);
  полная чистка spec/ — на решение пользователя. Реальные EXP-результаты
  (вывод машин) — только в hflab, в репо — только заглушки.
