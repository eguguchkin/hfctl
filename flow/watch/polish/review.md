   `tpl/python/watch_tui.py`, `Watch.draw()`, строки 1026–1029.

   - Что не так: при `log_h = 3` срез `-(0)` == `[0:]` → ВЕСЬ буфер; первая
     строка печатается в `log_top + 2` = строка нижней рамки → рамка рвётся

     непустом `log_view` (то есть на всём диапазоне ~H=10..20 с любой живой
     лентой). Нарушение DoD 3 («без наложений, рамки целы», размеры перечислены
     в DoD явно) и task §2.1 («при log_h = 3 контент/placeholder НЕ рисуются»
     — плейсхолдер этим условием уже защищён, контент — нет).
   - Что должно быть: контент ветвить тем же `log_h ≥ 4`, что и placeholder

     + selfcheck/grid-кейс с НЕПУСТЫМ log_view при log_h=3 (например 60×15:
     ни одного непробельного символа внутри строки нижней рамки). Тriage: impl
     (формулировка контракта §2.1 однозначна; псевдокод самого task §2.1

     архитектурного решения не требуется).

     перепуск машины для раунда 2 НЕ требуется.
