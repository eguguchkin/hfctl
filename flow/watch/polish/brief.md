# Brief: watch-tui-polish — доработка отображения (бэклог + замечания пользователя)

Следующий сабстэдж после закрытого `watch/watch-tui` (2026-11-13, APPROVED).
Движок не меняется (D4) — только `tpl/python/watch_tui.py` (+ диспетчер по
п.10) и скрипт EXP-001 (артефакт тестера).

## Goal (statable, checkable)
TUI `hfctl watch` — финальная полировка отображения: блоки прижаты к
наполнению (без пустых строк между рядами, освобождённая высота уходит
блоку «Логи»), человеческие имена метрик, выровненные значения, заглавные
названия блоков, самодостаточный статус-бар; закрытие визуального бэклога
(sparkline-окно, дубль лог-строки, usage rc).

## DoD (checklist; единственный носитель DoD)

1. Пустой строки между рядами блоков нет: второй ряд начинается
   непосредственно с нижней рамки первого ряда.
2. Высота блоков первого и второго рядов = ровно наполнение (строка
   заголовка + контентные строки + рамка сверху/снизу), без лишних
   вертикальных отступов. Освобождённая вертикаль идёт по остаточному
   принципу блоку «Логи» (нижняя зона, на всю ширину, до нижней границы
   терминала). Блоки одного ряда — одинаковой высоты (максимум пары).
3. При нехватке высоты (включая минимумы 80×24, 60×15, 40×10) — без краха,
   без наложений, рамки целы: клип контентных строк (хвостом), «Логи»
   держит минимальную высоту (конкретные числа — контракт task.md); на
   терминале выше минимума «Логи» растёт.
4. Названия блоков — с заглавной: «Движок», «Железо», «Скорость»,
   «Память», «Логи».
5. Имена метрик — человеко-читаемые (пользователь: «Tctl → CPU temp;
   пересмотреть все с точки зрения читаемости»). Итоговая таблица
   названий (TUI-блоки) — в task.md. Дробные температуры сохраняются
   (39.1°C — НЕ округлять в целые). «KV pages» остаётся («-» вне
   slot-режима — как есть, строку не прятать).
6. Значения в каждом блоке начинаются с одной и той же колонки (ярлыки
   дополнены до максимальной длины ярлыка блока + единый разделитель).
7. Статус-бар: разрыв в 1 колонку между зелёным bullet и «hfctl watch»;
   смысл клавиши `p` самодостаточен из строки статуса (состояние live/
   пауза + что делает `p` видно по самой подписи), помещается на 80 кол
   (усечение модели и разрыв ≥1 кол перед «интервал» — контракт fix round 2
   сохраняется).
8. Sparkline «Скорость»: окно ~60 c при интервале 2 c (≈30 точек), ширина
   = max(4, W//2−18) (или эквивалент, вписывается в рамку без отбрасывания
   свежих точек).
9. Лог-зона: дубля последней строки на границе сид → live нет (сид
   `--tail 50`, live-поток продолжает со следующей строки).
10. `hfctl` без аргументов → usage, rc=1 (internal checks AGENTS.md;
    доки уже говорят rc=1 — правится код, не доки).
11. Регрессия: полная (чек-лист AGENTS.md + pty 80×24/60×15/40×10 +
    TERM-фолбэки + «недоступен» + plain-периодичность + selfcheck +
    `status --json` чанковый порт + doctor); `tpl/bench/` md5 канон,
    `spec/state.md` цел; plain-режим (состав строки, D8) не тронут.
12. Внешняя приёмка (BLOCKED-EXTERNAL, GO пользователя + машина B):
    EXP-001 перепуск (лейаут и названия блоков изменились — критерии
    EXP-001 обновить ДО перепуска); EXP-002/003 действительны, если
    поимённый анализ покажет, что их критерии не затронуты (plain не
    меняется) — иначе перепуск.

## Constraints and known traps
- `watch_tui.py` — один файл, stdlib-only, синтаксис 3.8+.
- Статус-бар: геометрия `status_bar_layout()` — контракт fix round 2
  (разрыв ≥1 кол перед «интервал», строгий selfcheck-ассерт) не ломать.
- EXP-001 проверяет заголовки 5 блоков по имени — смена регистра ломает
  его критерий; скрипт правит тестер (артефакт) до перепуска.
- Plain-режим: состав строки (D8/SPEC) не менять — имена метрик из п.5
  касаются только TUI-блоков.
- Не коммитить; не трогать `tpl/bench/`, `spec/state.md` (AGENTS.md dev-flow).
