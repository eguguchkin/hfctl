# Task: watch/cache-tok-temp (механический, полностью специфицирован)

Контракт — `brief.md` рядом (решения пользователя каноничны). Файл правки —
`tpl/python/watch_tui.py` (TUI + plain в одном модуле).

## Что сделать

1. **Формат счётчика кэша.** Новая чистая функция (рядом с `fmti`/`fmt1`),
   например `fmt_tok(v)`: `None` → `'-'`; `<1000` → целое без разделителей
   (как `fmti`); `1000…999_999` → `f"{v/1000:.1f}k"`; `≥1_000_000` →
   `f"{v/1e6:.1f}M"`. Границы: 999 → `999`; 1000 → `1.0k`; 99_100 → `99.1k`;
   1_234_567 → `1.2M`.
   Применить: TUI-строка `('Cache tok', fmt_tok(...))` (сейчас
   `('Cache', fmti(...))`, watch_tui.py:1131) и plain-строка
   `cache: …` → `cache tok: …` с тем же форматом (`PLAIN_FULL`/`PLAIN_MIN`
   фикстуры согласовать: `4421` → `4.4k`).
2. **Пороги температур.** Новая чистая функция вида
   `temp_attr(deg, attr)` (или возвращающая имя цвета — как удобнее в этом
   коде): `None` → 0; `deg >= 90` → C_RED; `80 <= deg < 90` → C_YELLOW;
   иначе 0. Применить к **обеим** строкам блока «Железо»: `GPU temp`
   (сейчас без подсветки, watch_tui.py:1148) и `CPU temp` (сейчас
   `cpu > 80 → C_RED`, :1144 — заменить). Подсветка `GPU load`/`RAM` не
   трогается.
3. **Plain-стрим.** Тот же текст и пороги; цвета ANSI — только если stdout
   TTY (`sys.stdout.isatty()`); в pipe — чистый текст. Если plain-режим
   сейчас вообще не красится — просто добавить текст (`cache tok`), цвета в
   plain НЕ вводить отдельной работой: достаточно, что они появляются при
   TTY tam же общим механизмом, что и в TUI... (если такого механизма нет —
   в plain оставить БЕЗ цвета и записать это в dev-report как решение:
   DoD 2 считается выполненным, т.к. требования к цвету в pipe — «их нет»).
4. **Selfcheck** (`--selfcheck`): добавить проверки формата (`999`/`1.0k`/
   `99.1k`/`1.2M`) и температурных границ (`79.9→0`, `80→жёлтый`, `89.9→
   жёлтый`, `90→красный`, `None→0`); обновить затронутые константы
   (`PLAIN_FULL`, `PLAIN_MIN`, фикстура `metrics`). Все проверки зелёные,
   их число — в отчёте.
5. **Доки**: `spec/hfctl.md` §watch — строки про Cache и температуры
   привести в соответствие (коротко, без переписывания раздела).
